ACCDB Studio

Open, explore, and edit .accdb and .mdb databases natively on your Mac. No Windows, no Microsoft Access, no drivers.

Coming soon to the Mac App Store

Features

Tables and data

A fast datasheet for hundreds of thousands of records, with sorting, filters by field type, search, frozen and hidden columns.

Editing

Edit records, add and delete them, design new tables and change existing ones. Nothing is written until you save, with an optional backup copy.

Queries

Run saved select, crosstab, union, and action queries, or write your own SQL in an editor with syntax highlighting and autocomplete.

VBA code

Read every module with syntax highlighting, see the SQL built inside the code, and run many procedures directly on the Mac.

Import and export

Excel, CSV, Parquet, JSON, XML, HTML, SQL scripts, and whole-database export to SQLite, with relationships and indexes.

Relationships and documentation

An interactive relationship diagram, linked-table management, and a printable report of the whole database.

New and compact databases

Create blank databases and compact existing ones to reclaim unused space.

Made for macOS

Native menus and shortcuts, light and dark appearance, Apple silicon and Intel. Available in English, Italian, Spanish, French, German, Chinese, and Hindi.

Supported files

Databases created with Access 97 through Access 2019 / Microsoft 365: .accdb, .mdb, .accde, and .mde. Requires macOS 11 Big Sur or later.

Support

Do I need Microsoft Access or Windows?
No. ACCDB Studio reads and writes the database file format directly.
Will my database files be changed?
Only when you save. Until then every change stays in memory and can be discarded. You can also turn on a backup copy in Settings, made before the first save of each file.
Are password-protected databases supported?
Not yet. Support for encrypted databases is planned.
Can I use forms and reports?
Forms, reports, and macros are listed and their VBA code can be read, but their layout is not displayed yet. VBA procedures that rely on forms, Windows APIs, or COM automation cannot run on a Mac.
How do I report a problem?
Write to the address below with your macOS version, the app version (ACCDB Studio → About), and the steps that lead to the problem. If it concerns a specific file, a small sample that shows the issue helps a lot. Please don't send confidential data.
