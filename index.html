What you can do

Browse and edit data
Sort, filter, search, freeze and hide columns. Edit records, attachments, and multi-value fields. Changes stay in memory until you save, with an optional backup copy.
Run queries
Saved select, crosstab, union, and action queries, parameters included, plus an SQL editor for your own.
Change the structure
Create tables with keys and indexes. Add, rename, and delete fields, and change data types after a check of what would be lost.
Read and run VBA
Every module with syntax highlighting and the SQL built inside the code. Many procedures run directly on the Mac.
Import and export
Excel, CSV, Parquet, JSON, XML, HTML, and SQL scripts. Whole databases to SQLite, with relationships and indexes.
Open protected files
Password-protected databases open after you type the password, which stays in memory only.
Understand a database
A relationship diagram, linked-table management, and a printable report of every object.
Keep files tidy
Create blank databases and compact existing ones to reclaim unused space.
Feel at home on macOS
Native menus and shortcuts, light and dark appearance, numbers and dates in your region’s format. In English, Italian, Spanish, French, German, Chinese, and Hindi.

Support

Do I need Microsoft Access or Windows?

No. ACCDB Studio reads and writes the database file format directly.

Will my database files be changed?

Only when you save. Until then every change stays in memory and can be discarded. You can also turn on a backup copy in Settings, made before the first save of each file.

Are password-protected databases supported?

Yes. When you open a protected file, ACCDB Studio asks for its password and keeps it in memory only for that session. Setting or removing a password isn’t available yet.

Can I use forms and reports?

Forms, reports, and macros are listed and their VBA code can be read, but their layout isn’t displayed yet. VBA procedures that rely on forms, Windows APIs, or COM automation can’t run on a Mac.

Is my data sent anywhere?

No. The app doesn’t connect to the internet and contains no analytics. See the privacy policy.

How do I report a problem?

Write to the address below with your macOS version, the app version (ACCDB Studio → About), and the steps that lead to the problem. If it concerns a specific file, a small sample that shows the issue helps a lot. Please don’t send confidential data.
