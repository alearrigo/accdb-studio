What you can do

Browse and edit every table.

Sort, search, freeze and hide columns. Edit records, attachments, and multi-value fields. Thousands of records scroll instantly, and changes stay in memory until you save, with an optional backup copy. Password-protected files open after you type the password, which is kept in memory only.

Filter by what a field holds.

Pick values from a list, or set a condition that fits the field type: text, numbers, dates, yes/no. Filters on several columns combine.

Run queries, read the VBA.

Saved select, crosstab, union, and action queries, parameters included, plus an SQL editor with highlighting and autocomplete. Every VBA module opens with syntax highlighting and the SQL built inside the code, and many procedures run directly on the Mac.

Change how tables are built.

Create tables with keys and indexes. Add, rename, and delete fields, and change a data type after a check of what would be lost. See the relationship diagram, manage linked tables, print a report of every object, create blank databases, and compact old ones.

Take the data anywhere.

Import and export Excel, CSV, Parquet, JSON, XML, HTML, and SQL scripts. Move a whole database to SQLite, relationships and indexes included.

Feels like it belongs on a Mac.

Native menus and shortcuts, light and dark appearance, numbers and dates in your region’s format. In English, Italian, Spanish, French, German, Chinese, and Hindi.

Support

Do I need Microsoft Access or Windows?

No. ACCDB Studio reads and writes the database file format directly, on the Mac.

Will my database files be changed?

Only when you save. Until then every change stays in memory and can be discarded. You can also turn on a backup copy in Settings, made before the first save of each file.

Are password-protected databases supported?

Yes. When you open a protected file, ACCDB Studio asks for its password and keeps it in memory only for that session. Setting or removing a password isn’t available yet.

Can I use forms and reports?

Forms, reports, and macros are listed and their VBA code can be read, but their layout isn’t displayed yet. VBA procedures that rely on forms, Windows APIs, or COM automation can’t run on a Mac.

Is my data sent anywhere?

No. The app doesn’t connect to the internet and contains no analytics. See the privacy policy.

How do I report a problem?

Write to the address below with the details listed there. If it concerns a specific file, a small sample that shows the issue helps a lot.

Questions or problems? Write to info@alessandroarrigo.com
